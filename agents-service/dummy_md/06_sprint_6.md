# Sprint 6: Graphs and Dynamic Programming

**Dates:** July 6 - July 12 (7 Days)
**Focus:** Graph traversal, shortest paths, and introductory dynamic programming

## Daily Breakdown

### Day 36: Graph Representations and BFS (July 6)

- **Description:** Represent graphs with adjacency lists and traverse them with BFS.
- **Objectives:**
  - Build an adjacency list from edges
  - Solve a shortest-path-in-an-unweighted-graph problem
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Graph Problems](https://leetcode.com/tag/graph/) - LeetCode (Required)

### Day 37: Depth-First Search and Components (July 7)

- **Description:** Use DFS to explore connected components and grid regions.
- **Objectives:**
  - Implement recursive or iterative DFS
  - Solve a connected-components or island-counting problem
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Number of Islands](https://leetcode.com/problems/number-of-islands/) - LeetCode (Required)

### Day 38: Topological Sorting (July 8)

- **Description:** Order tasks in a directed acyclic graph using indegrees or DFS.
- **Objectives:**
  - Detect whether a course dependency graph has a cycle
  - Produce a valid topological ordering when possible
- **Estimated Time:** 120 minutes
- **Resources:**
  - [Course Schedule](https://leetcode.com/problems/course-schedule/) - LeetCode (Required)

### Day 39: Shortest Paths and Union-Find (July 9)

- **Description:** Select a graph strategy for connectivity and weighted path problems.
- **Objectives:**
  - Implement disjoint-set union with path compression
  - Compare BFS and Dijkstra use cases
- **Estimated Time:** 120 minutes
- **Resources:**
  - [Graph Algorithms](https://cp-algorithms.com/graph/) - Documentation (Optional)

### Day 40: Dynamic Programming Foundations (July 10)

- **Description:** Define states and transitions for overlapping subproblems.
- **Objectives:**
  - Convert a simple recurrence into memoized and tabulated solutions
  - Solve a climbing-stairs variation
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Climbing Stairs](https://leetcode.com/problems/climbing-stairs/) - LeetCode (Required)

### Day 41: One-Dimensional Dynamic Programming (July 11)

- **Description:** Build one-dimensional DP solutions and identify their base cases.
- **Objectives:**
  - Solve a house-robber-style problem
  - Reduce space when only prior states are needed
- **Estimated Time:** 120 minutes
- **Resources:**
  - [House Robber](https://leetcode.com/problems/house-robber/) - LeetCode (Required)

### Day 42: Sprint 6 Review (July 12)

- **Description:** Review graph traversal and introductory DP under a short time limit.
- **Objectives:**
  - Complete one graph problem and one DP problem
  - State each solution's time and space complexity
- **Estimated Time:** 120 minutes
- **Resources:**
  - [Dynamic Programming Problems](https://leetcode.com/tag/dynamic-programming/) - LeetCode (Optional)

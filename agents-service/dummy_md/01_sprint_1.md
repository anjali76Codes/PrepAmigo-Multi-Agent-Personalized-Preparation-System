# Sprint 1: DSA Fundamentals

**Dates:** June 1 - June 7 (7 Days)
**Focus:** Arrays, Hashing, and Two Pointers

## Daily Breakdown

### Day 1: Arrays and Hashing (June 1)

- **Description:** Learn array traversal, two pointers, and hash maps.
- **Objectives:**
  - Understand time complexity
  - Solve 5 LeetCode easy problems
- **Estimated Time:** 120 minutes
- **Resources:**
  - [Arrays 101](https://youtube.com/arrays101) - YouTube (Required)
  - [Hash Map Guide](https://medium.com/hashmaps) - Medium (Optional)

### Day 2: Two Pointers (June 2)

- **Description:** Master the two-pointer technique for sorted arrays.
- **Objectives:**
  - Solve 3 medium LeetCode problems
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Two Pointers Pattern](https://leetcode.com/two-pointers) - LeetCode (Required)

### Day 3: Sliding Window (June 3)

- **Description:** Use fixed and variable windows to process contiguous ranges efficiently.
- **Objectives:**
  - Implement fixed-size and variable-size windows
  - Solve 3 sliding-window problems
- **Estimated Time:** 100 minutes
- **Resources:**
  - [Sliding Window Problems](https://leetcode.com/tag/sliding-window/) - LeetCode (Required)

### Day 4: Prefix Sums (June 4)

- **Description:** Build prefix sums to answer range queries and identify subarrays.
- **Objectives:**
  - Implement prefix-sum arrays
  - Solve 3 range-sum or subarray problems
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Prefix Sum Problems](https://leetcode.com/tag/prefix-sum/) - LeetCode (Required)

### Day 5: Hashing Patterns (June 5)

- **Description:** Apply sets and maps to frequency counting and lookup problems.
- **Objectives:**
  - Compare set and map operations and their complexity
  - Solve 4 frequency-counting problems
- **Estimated Time:** 100 minutes
- **Resources:**
  - [Hash Table Problems](https://leetcode.com/tag/hash-table/) - LeetCode (Required)

### Day 6: Arrays Practice Set (June 6)

- **Description:** Combine array traversal, hashing, prefix sums, and two pointers.
- **Objectives:**
  - Solve 4 mixed easy and medium problems
  - Write down the invariant used in each solution
- **Estimated Time:** 120 minutes
- **Resources:**
  - [Array Problems](https://leetcode.com/tag/array/) - LeetCode (Required)

### Day 7: Sprint 1 Review (June 7)

- **Description:** Consolidate the week's patterns and revisit problems that took the longest.
- **Objectives:**
  - Re-solve 2 previously missed problems without notes
  - Record complexity and takeaways for each core pattern
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Big-O Cheat Sheet](https://www.bigocheatsheet.com/) - Article (Optional)

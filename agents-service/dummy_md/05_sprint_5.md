# Sprint 5: Trees and Heaps

**Dates:** June 29 - July 5 (7 Days)
**Focus:** Tree traversals, binary search trees, heaps, and priority queues

## Daily Breakdown

### Day 29: Tree Structure and Traversals (June 29)

- **Description:** Traverse binary trees recursively and iteratively.
- **Objectives:**
  - Implement preorder, inorder, and postorder traversals
  - Explain recursion state and base cases
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Binary Tree Traversal](https://leetcode.com/tag/tree/) - LeetCode (Required)

### Day 30: Breadth-First Search on Trees (June 30)

- **Description:** Process tree nodes level by level with a queue.
- **Objectives:**
  - Implement level-order traversal
  - Solve a tree-depth or level-aggregation problem
- **Estimated Time:** 100 minutes
- **Resources:**
  - [Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/) - LeetCode (Required)

### Day 31: Binary Search Trees (July 1)

- **Description:** Use the ordering invariant of binary search trees.
- **Objectives:**
  - Validate a binary search tree
  - Find a lowest common ancestor in a BST
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Validate Binary Search Tree](https://leetcode.com/problems/validate-binary-search-tree/) - LeetCode (Required)

### Day 32: Tree Paths and Recursion (July 2)

- **Description:** Track path state and aggregate results through recursive tree walks.
- **Objectives:**
  - Solve a root-to-leaf path problem
  - Distinguish global results from values returned by recursion
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Path Sum](https://leetcode.com/problems/path-sum/) - LeetCode (Required)

### Day 33: Heaps and Priority Queues (July 3)

- **Description:** Maintain an efficient minimum or maximum element with a heap.
- **Objectives:**
  - Explain heap push and pop complexity
  - Solve a top-K elements problem
- **Estimated Time:** 100 minutes
- **Resources:**
  - [Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/) - LeetCode (Required)

### Day 34: Tree and Heap Practice (July 4)

- **Description:** Apply traversal, ordering, and priority-queue patterns in timed practice.
- **Objectives:**
  - Complete 3 medium tree or heap problems
  - Revisit any solution with unclear complexity
- **Estimated Time:** 130 minutes
- **Resources:**
  - [Heap Problems](https://leetcode.com/tag/heap-priority-queue/) - LeetCode (Required)

### Day 35: Sprint 5 Review (July 5)

- **Description:** Review tree traversal templates, BST invariants, and heap use cases.
- **Objectives:**
  - Re-implement one traversal and one heap operation from memory
  - Summarize when to use a heap instead of sorting
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Tree Problems](https://leetcode.com/tag/tree/) - LeetCode (Optional)

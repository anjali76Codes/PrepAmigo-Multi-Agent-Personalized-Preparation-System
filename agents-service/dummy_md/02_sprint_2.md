# Sprint 2: Linked Lists

**Dates:** June 8 - June 14 (7 Days)
**Focus:** Singly and Doubly Linked Lists

## Daily Breakdown

### Day 8: Singly Linked Lists (June 8)

- **Description:** Implement a singly linked list from scratch.
- **Objectives:**
  - Understand node structures
  - Implement insertion, deletion, and traversal
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Linked List Guide](https://medium.com/linkedlists) - Medium (Required)

### Day 9: Fast and Slow Pointers (June 9)

- **Description:** Use two pointers moving at different speeds to detect list structure.
- **Objectives:**
  - Find a list's midpoint
  - Detect a cycle and identify its entry point
- **Estimated Time:** 100 minutes
- **Resources:**
  - [Linked List Cycle](https://leetcode.com/problems/linked-list-cycle/) - LeetCode (Required)

### Day 10: Reversing Linked Lists (June 10)

- **Description:** Reverse linked lists iteratively and recursively.
- **Objectives:**
  - Explain the previous, current, and next pointer invariant
  - Solve the reverse linked list problem in both styles
- **Estimated Time:** 100 minutes
- **Resources:**
  - [Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/) - LeetCode (Required)

### Day 11: Merge and Reorder Lists (June 11)

- **Description:** Manipulate links to merge sorted lists and reorder nodes.
- **Objectives:**
  - Merge two sorted linked lists
  - Reorder a list using splitting, reversing, and merging
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Merge Two Sorted Lists](https://leetcode.com/problems/merge-two-sorted-lists/) - LeetCode (Required)

### Day 12: Doubly Linked Lists (June 12)

- **Description:** Study bidirectional links and their tradeoffs for updates.
- **Objectives:**
  - Implement a doubly linked list with safe insert and remove operations
  - Explain when a doubly linked list is preferable
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Doubly Linked List](https://www.geeksforgeeks.org/dsa/doubly-linked-list/) - GeeksforGeeks (Optional)

### Day 13: Linked List Problem Set (June 13)

- **Description:** Practice pointer manipulation across common linked-list tasks.
- **Objectives:**
  - Solve 3 medium linked-list problems
  - Test edge cases for empty and single-node lists
- **Estimated Time:** 120 minutes
- **Resources:**
  - [Linked List Problems](https://leetcode.com/tag/linked-list/) - LeetCode (Required)

### Day 14: Sprint 2 Review (June 14)

- **Description:** Review pointer invariants and compare list operations with arrays.
- **Objectives:**
  - Re-solve one cycle problem and one reversal problem
  - Summarize operation complexity for singly and doubly linked lists
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Linked List Problems](https://leetcode.com/tag/linked-list/) - LeetCode (Optional)

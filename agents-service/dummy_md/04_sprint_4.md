# Sprint 4: Binary Search and Sorting

**Dates:** June 22 - June 28 (7 Days)
**Focus:** Search boundaries, binary search on answers, and sorting patterns

## Daily Breakdown

### Day 22: Binary Search Fundamentals (June 22)

- **Description:** Search sorted arrays while maintaining a precise search interval.
- **Objectives:**
  - Implement iterative binary search
  - State the loop invariant and termination condition
- **Estimated Time:** 90 minutes
- **Resources:**
  - [Binary Search](https://leetcode.com/problems/binary-search/) - LeetCode (Required)

### Day 23: Lower and Upper Bounds (June 23)

- **Description:** Find insertion positions and first or last matching values.
- **Objectives:**
  - Implement lower-bound and upper-bound searches
  - Solve 3 boundary-focused problems
- **Estimated Time:** 110 minutes
- **Resources:**
  - [Search Insert Position](https://leetcode.com/problems/search-insert-position/) - LeetCode (Required)

### Day 24: Binary Search on the Answer (June 24)

- **Description:** Search a numeric answer space using a monotonic feasibility check.

- **Estimated Time:** 120 minutes
- **Resources:**
